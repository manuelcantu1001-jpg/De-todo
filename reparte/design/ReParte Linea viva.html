Cómo funciona

Tres cuadrosTres filtros de ruido con semilla distinta se turnan. El orden no se repite en seco: 1, 2, 3, 2, 1… para que no se note el ciclo.
8 cuadros por segundoEs la cadencia típica del stop motion. Más rápido se siente vibración; más lento, tartamudeo.
Respeta "reducir movimiento"Si el teléfono tiene activado reducir movimiento, la línea se queda quieta.
Casi gratisNo añade imágenes. Se detiene cuando la pestaña no está visible para no gastar batería.
